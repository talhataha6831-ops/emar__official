# EMAR — Official Luxury Store

This repository is the official EMAR luxury storefront scaffold built with Next.js, Tailwind CSS, Framer Motion, and Supabase.

Environment variables (set in Vercel or .env.local):

- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- NEXT_PUBLIC_EMAR_WHATSAPP_TARGET (e.g. +923257851162)
- NEXT_PUBLIC_EMAR_VIP_WHATSAPP
- NEXT_PUBLIC_SUPPORT_EMAIL

Run locally:

1. npm install
2. npm run dev
